%MENUS%
Image (no object selected)
Arrows : move the mouse cursor (Shift: 5 pixels)
Return : click at the mouse cursor (e.g. lock-click lineouts)
Backspace : delete the selected object (asks if it belongs to a window)
Lines (the selected one)
Arrows : move the line (Shift: 10 pixels)
w : line properties window
b : toggle Bezier line
c : toggle closed line
Shift+c : center the line on the image
s : toggle antialias
a : append point
p : prepend point
d : delete point
x : put the first 2 points horizontal
y : put the first 2 points vertical
r : put the first 4 points in a rectangle
Shift+r : expand the 4 points to the image
Return, Esc : stop adding points
Rectangles (the selected one)
Arrows : move the rectangle (Shift: 10 pixels)
w : rectangle properties window
e : expand to the whole image
x : expand horizontally
y : expand vertically
i : intersection with the image
s : open the submatrix as a new image
c : center in the image
Shift+c : copy the points
Shift+v : paste the points
Esc : cancel the rectangle being created
Points (the selected one)
Arrows : move the point (Shift: 10 pixels)
w : point properties window
Any analysis window
%CTRL%%OPTION%%COMMAND%S : save a screenshot of the window in the home folder
%CTRL%%OPTION%%COMMAND%J : copy the status of the window, to be reused in the JavaScript console
